# Portfolio Rebalance Check Skill

## วัตถุประสงค์
ตรวจสอบว่าสัดส่วนการลงทุนปัจจุบันของพอร์ตเบี่ยงเบนจาก Target Allocation เกินเกณฑ์ควบคุมความเสี่ยงหรือไม่ พร้อมสรุปคำแนะนำการ Rebalance

## ขั้นตอนการทำงาน
1. ดึงสถานะพอร์ตล่าสุดผ่านเครื่องมือ `get_portfolio_overview`
2. ดึงแผนคำแนะนำและความเสี่ยงผ่านเครื่องมือ `get_portfolio_advisory_and_alerts`
3. หากมีความจำเป็นต้องคำนวณการปรับสัดส่วน ให้เขียนสคริปต์ผ่าน `run_sandbox_calculation` โดยใช้ `Decimal` ในการคำนวณจำนวนเงินและหน่วยหุ้นเสมอ
4. สรุปผลให้ผู้ใช้ทราบอย่างกระชับ นุ่มนวล และชัดเจน
