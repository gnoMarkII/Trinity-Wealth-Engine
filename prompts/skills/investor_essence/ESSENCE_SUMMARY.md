# คำสั่งแรก — สรุปแก่นแท้ในการลงทุนหลังครบ 10 ข้อ

## คำสั่งฐาน
เพื่อดึงเป้าหมายออกมาจากจิตใต้สำนึก กรุณาตั้งคำถามกับผู้ใช้จำนวน 10 ข้อ โดยแต่ละข้อให้มีตัวเลือก 4 ข้อ ให้ถามทีละข้อตามลำดับ และดำเนินการโดยอิงจากคำตอบของผู้ใช้ จากนั้นให้กำหนดเป้าหมายให้ชัดเจน และสรุปออกมาเป็น "แก่นแท้ในการลงทุน" รูปแบบผลลัพธ์: ระหว่างที่ดำเนินการถามให้เป็นรูปแบบถาม-ตอบ (Q&A) ส่วนผลลัพธ์ตอนสรุปให้อยู่ในรูปแบบของข้อๆ (Bulleted list)

## กติกาการสรุป
1. นำคำถามและคำตอบทั้ง 10 ข้อในประวัติการสัมภาษณ์มาสังเคราะห์
2. สรุปเป็น "Bulleted list" (รายการข้อๆ) แยกแยะ:
   - "สิ่งที่ผู้ใช้บอกไว้" (source_kind = "user_stated")
   - "การตีความของ AI ที่มีหลักฐานรองรับ" (source_kind = "ai_inferred")
3. ทุก claim ต้องมี evidence_refs เชื่อมโยงกลับไปยัง question_id และ quote ของคำตอบจริง
4. ประโยคเด่น (statement): สรุปแก่นแท้ 1-2 ประโยคที่กระชับและเฉพาะตัว
5. ระบุประเด็นที่ยังไม่ชัดเจน (unresolved_topics) หากข้อมูลบางเสาหลักยังไม่เพียงพอ

## Output JSON Schema
```json
{
  "statement": "สรุปแก่นแท้การลงทุน 1-2 ประโยค",
  "claims": [
    {
      "text": "ข้อความสรุปแก่นแท้",
      "source_kind": "user_stated",
      "supporting_question_ids": ["q_1"],
      "quote": "คำพูดหรือตัวเลือกที่ผู้ใช้ตอบ",
      "evidence_type": "actual_experience"
    }
  ],
  "unresolved_topics": ["ประเด็นที่ยังต้องทบทวน"],
  "coverage_report": [
    {
      "topic": "life_goals",
      "status": "covered",
      "supporting_answer_ids": ["ans_1"]
    }
  ]
}
```
