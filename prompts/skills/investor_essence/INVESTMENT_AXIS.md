# คำสั่งสอง — แปลงแก่นแท้เป็นแกนหลักการลงทุน (8 หัวข้อ)

## คำสั่งฐาน
กรุณานำ "แก่นแท้ในการลงทุน" ที่ได้ข้อสรุปด้านบน มาแปลงให้เป็นรูปธรรมเพื่อสร้างเป็น "แกนหลักในการลงทุน" ที่สามารถนำไปใช้ลงทุนได้จริง เงื่อนไขข้อจำกัด: แต่ละหัวข้อจะต้อง "ใช้ประโยคสั้นกระชับ + มีตัวเลขที่เป็นรูปธรรม" และในตอนท้ายให้ระบุ "สิ่งที่จะไม่ทำ" มาอย่างน้อย 3 ข้อ รูปแบบผลลัพธ์: แบบเป็นข้อๆ (Bulleted list) หัวข้อ: นโยบายพื้นฐาน / ระดับความเสี่ยงที่ยอมรับได้ (MDD สูงสุดต่อปี・ขีดจำกัดผลขาดทุนต่อ 1 การซื้อขาย) / เป้าหมาย (ลงทุน・ไม่ลงทุน) / วิธีการ (หลัก・เสริม) / กรอบเวลาในการลงทุน / การจัดสรรสินทรัพย์ (สัดส่วน・ความถี่ในการปรับสมดุลพอร์ต (Rebalance)) / ชื่อนักลงทุนที่ใช้เป็นต้นแบบ / สิ่งที่จะไม่ทำ

## กติกาการร่าง
1. ครบทั้ง 8 หัวข้อ ห้ามตกหล่น
2. ตัวเลขที่เป็นรูปธรรม: MDD สูงสุดต่อปี (%), ขีดจำกัดผลขาดทุนต่อ 1 การซื้อขาย (%), สัดส่วนการจัดสรรสินทรัพย์รวม 100%
3. ในตอนท้ายต้องมี "สิ่งที่จะไม่ทำ" อย่างน้อย 3 ข้อที่ไม่ซ้ำกัน
4. อ้างอิงเฉพาะแก่นแท้ฉบับยืนยันและบริบทการเงินที่ได้รับเท่านั้น
